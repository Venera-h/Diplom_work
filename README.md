# Сайт школы образования в Китае AI Kitai

Веб-платформа для образовательного агентства по поступлению в китайские университеты.

Стек

Frontend: HTML5, CSS3, JavaScript, React, Vite

Backend: Python, FastAPI, SQLAlchemy, SQLite

Дополнительно: Telegram Bot API, Leaflet.js / Яндекс.Карты

Микросервисы

| Сервис | Порт | Описание |
|--------|------|----------|
| auth | 8000 | Аутентификация пользователей |
| CRUD | 8001 | Университеты и программы обучения |
| orders | 8002 | Система заявок |
| packages | 8003 | Пакеты услуг |

Функционал

- 🎓 Каталог университетов Китая с таблицей стоимости
- 🗺️ Интерактивная карта университетов
- 📋 Каталог программ обучения с фильтрацией
- 🎯 Квиз подбора программы
- 🗺️ Roadmap поступления
- 📩 Форма заявки с отправкой в Telegram
- 👤 Личный кабинет студента с трекером статуса заявки
- 📰 Лента новостей из Telegram канала @ai_kitai_service

Запуск

```bash
# Бэкенд
cd auth && python3 main.py
cd CRUD && python3 main.py
cd orders && python3 main.py
cd packages && python3 main.py

# Фронтенд
cd frontend && npm run dev
```
